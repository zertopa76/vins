# VinPartsHelper — помощник механика (этап 1: сайт vwts.ru)

Консольная программа: по модели/двигателю и названию операции («цепь ГРМ») находит
руководство на vwts.ru и показывает, какие ещё детали нужно заменить вместе с ней —
с пометкой **обязательно / рекомендуется / по условию / проверить**, цитатой и ссылкой
на источник.

> Результат строится автоматически из текста руководства и **требует проверки по
> первоисточнику**. Это справочник, а не замена официальной документации.

## Запуск окна приложения (рекомендуется)

Программа открывается в **собственном окне** (без браузера, вкладок и адресной строки; сделано на
pywebview: на Windows это встроенный WebView2, на Mac WebKit). Командная строка не нужна:

- **Windows:** установите Python 3.13 (python.org, отметьте «Add python.exe to PATH»), затем дважды
  щёлкните **`Запуск Windows.bat`**. При первом запуске он сам создаёт окружение и ставит пакеты.
- **Mac:** установите Python 3.13 (python.org/downloads/macos), затем дважды щёлкните
  **`Запуск Mac.command`**. Если macOS не даёт открыть файл: правый щелчок → «Открыть», или один раз
  выполните в Терминале `chmod +x "Запуск Mac.command"`.
- Из терминала: `python -m vinparts gui` (опции `--browser`, `--no-open`, `--port`).

Что есть в окне:
1. **Поиск на vwts.ru:** операция, модель, двигатель, год, VIN (подсказки из индекса, VIN даёт марку и год).
   Перед скачиванием документов программа показывает окно «Скачать?» со списком адресов.
2. **Результат:** список деталей с пометками «Обязательно / Рекомендуется / По состоянию / Проверить»,
   цитата из руководства, кликабельная ссылка на источник (PDF открывается на нужной странице),
   кнопка **«Показать страницу руководства»**: картинка страницы с жёлтой подсветкой нужного места
   (клик по картинке увеличивает). Фильтр по типу, «Скопировать список», «Печать».
3. **Свой файл:** перетащите PDF/HTML/TXT (например, выгруженное руководство): разбор идёт локально.
4. **Источники и настройки:** индекс, паузы, User-Agent, папка данных, статус LLM.
5. Переключатель RU/EN и кнопка «Выход».

Требования к окну: на Windows нужен **Microsoft Edge WebView2 Runtime**. Он есть в Windows 11 и в
большинстве обновлённых Windows 10; если его нет, программа напишет об этом и откроется в браузере
(тогда скачайте «Evergreen Runtime» со страницы developer.microsoft.com/microsoft-edge/webview2).
Ссылки на источники открываются в обычном браузере, остальное остаётся внутри окна.
Запуск с `--browser` показывает интерфейс во вкладке браузера.

Окно работает через локальный сервер на 127.0.0.1 (наружу не открывается, защищён случайным токеном).
Картинки страниц рисует `pypdfium2`; без него остальное работает, но кнопки с картинками не будет.
Картинки есть только у PDF-источников: у HTML-страниц сайта страниц нет, там остаются цитата и ссылка.

## Готовое приложение (.exe / .app)

Чтобы запускать как обычную программу (значок, без консоли), её нужно один раз собрать на самом
компьютере, где она будет работать. Нужен интернет и Python 3.13 (на 3.14 библиотека окна для Windows может не установиться).

- **Windows:** дважды щёлкните **`Сборка exe (Windows).bat`**. Через несколько минут появится
  **один файл `dist\VinPartsHelper.exe`** (никаких папок с сотнями файлов); скрипт предложит создать ярлык
  на рабочем столе. Файл можно скопировать куда угодно. Python после сборки уже не нужен. Первый запуск
  занимает несколько секунд: программа распаковывается во временную папку.
- **Mac:** **`Сборка приложения (Mac).command`** создаёт `dist/VinPartsHelper.app`.
  Перетащите его в «Программы».
- Первый запуск: Windows SmartScreen может показать «Система Windows защитила ваш компьютер»: нажмите
  «Подробнее» → «Выполнить в любом случае» (программа не подписана цифровой подписью). Антивирусы иногда
  ошибочно ругаются на программы, собранные PyInstaller; тогда добавьте папку в исключения. На Mac:
  правый щелчок по программе → «Открыть».
- Приложение запускается в своём окне. Закрыли окно (или нажали «Выход»), и программа завершилась сама.
  Повторный запуск выводит на передний план уже открытое окно. Если программа не смогла запуститься, она покажет
  сообщение и запишет подробности в `app.log` в папке данных.
- После обновления программы сборку нужно повторить.

## Как передать программу механику без установки Python

Механику нужен только один файл `VinPartsHelper.exe` (для Mac: `VinPartsHelper.app`), распаковывать ничего не надо. Python ему не нужен
(он вшит в сборку). Собрать архив нужно один раз, и есть два способа:

1. **Облачная сборка на GitHub (подходит, если у вас Mac):** загрузите папку проекта в репозиторий GitHub
   (можно приватный), откройте вкладку **Actions** → **Build apps** → **Run workflow**. Через несколько
   минут внизу страницы запуска, в разделе **Artifacts**, появятся `VinPartsHelper-Windows` (внутри один `VinPartsHelper.exe`) и
   `VinPartsHelper-Mac.zip` (внутри `VinPartsHelper.app`). Файл сборки: `.github/workflows/build.yml`. Сборка Mac рассчитана на
   Mac с процессором Apple (M1 и новее).
2. **На любом компьютере с Windows:** `Сборка exe (Windows).bat` (нужен Python только на этом компьютере).

После обновления программы сборку нужно повторить и отдать механику новый архив. Папки данных
(индекс, кэш) лежат отдельно и при обновлении не теряются. Для окна на Windows нужен WebView2 Runtime
(есть в Windows 11 и в большинстве Windows 10).

## Библиотека руководств (если сайт отдаёт страницу вместо PDF)

vwts.ru на ссылку PDF отдаёт страницу «Скачивание файла…» с отсчётом в 9 секунд, а не сам файл.
Программа эту страницу не обходит и под браузер не маскируется. Что делать:

1. После поиска в окне появится блок **«Эти руководства нужно скачать самим»**: названия и имена файлов.
2. Нажмите **«Открыть в браузере»**, дождитесь отсчёта и сохраните файл (имя не меняйте).
3. Перетащите скачанные PDF (можно несколько сразу) в этот же блок или на вкладку
   **«Источники и настройки» → «Библиотека руководств»**, затем нажмите «Повторить поиск».

Файлы хранятся в папке `library` внутри папки данных. Файл сопоставляется со ссылкой сайта по имени
(`vw-golf-7-maintenance-eng.pdf`; приписка « (1)» от браузера не мешает). Найденный в библиотеке файл
сайт больше не запрашивает: поиск быстрее, вопроса «Скачать?» по нему нет, ссылка в результате остаётся
на оригинал на сайте. Ссылка на «страницу-отсчёт» при этом законно открывается в обычном браузере.
Разовый вариант без библиотеки: вкладка **«Свой файл»**.
Чтобы программа могла качать файлы сама, напишите владельцу сайта (vwts_admin@mail.ru): попросите прямые
ссылки на файлы или разрешение. Я не юрист; права на руководства принадлежат производителям.

Программа сообщает причину: «Сервер вернул не PDF, а веб-страницу», «Файл скачан не полностью» или
«Загрузка оборвалась». Начало неудачного ответа сохраняется в папке `debug` внутри папки данных
(путь указан в сообщении). Плохие ответы в кэше не остаются: при следующем запросе файл скачивается заново.

## Язык результатов и индекс всех моделей

- **Язык.** Переключатель RU / EN меняет интерфейс, сообщения и вывод: на русском название детали идёт
  по-русски (словарь терминов), с пояснением, что сказано в руководстве, а оригинальная английская цитата
  остаётся с подписью «Оригинал» (по ней проверяют). Руководства на сайте английские, автоматического
  перевода целых предложений без языковой модели нет: деталь, которой нет в словаре, показывается
  по-английски с пометкой. Технический текст сетевых ошибок остаётся на русском.
- **Все модели сайта.** Список моделей (VW, Audi, Škoda, SEAT) берётся с главной страницы vwts.ru и сразу
  доступен в поле «Модель». Поиск сам дозагружает страницу нужной модели и страницы двигателей, если их
  ещё нет в индексе (несколько запросов, ход виден в окне). Кнопка **«Загрузить все модели»** один раз
  проходит по страницам всех моделей в фоне (примерно 200+ страниц с паузой 4 с, около 15 минут; можно
  отменить, уже загруженное сохраняется и повторно не качается). В консоли: `python -m vinparts index --all-models`.

## Про скраперы и скорость

Скорость поиска ограничена не инструментом, а вежливой паузой между запросами к сайту, и её не нужно
обходить: сайт закрыл в robots.txt многих роботов (Wget, SEO-пауков, ИИ-краулеров). Быстрее и честнее так:
один раз загрузить все модели (индекс хранится локально), держать скачанные руководства в библиотеке
и читать их с диска. Тогда поиск идёт мгновенно, и сайт не нагружается.

## Установка вручную (Windows, PowerShell)

```powershell
cd vinparts_project
py -3.14 -m venv .venv      # или py -3.13
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m vinparts --help
```

macOS / Linux:

```bash
python3.14 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m vinparts --help
```

Тесты (работают офлайн): `pip install -r requirements-dev.txt && pytest`

## Команды

| Команда | Что делает |
|---|---|
| `python -m vinparts gui` | Оконное приложение (см. выше) |
| `python -m vinparts vin WVWZZZ...` | Расшифровка VIN (марка, год; WMI только VAG) |
| `python -m vinparts ops` | Список поддерживаемых операций |
| `python -m vinparts recon` | **Запустите первой.** Скачивает главную vwts.ru и показывает, что распознано |
| `python -m vinparts recon --url https://vwts.ru/vw_golf7_5g.html` | То же для страницы модели |
| `python -m vinparts index [--model golf]` | Строит локальный индекс документов (SQLite) |
| `python -m vinparts docs` | Что лежит в индексе |
| `python -m vinparts ask --op "цепь грм" --model golf --engine CJSA --year 2013` | Основной запрос |
| `python -m vinparts analyze-file файл.pdf --op "цепь грм"` | Анализ локального PDF/HTML/TXT (без сети) |

Глобальные опции: `--data-dir`, `--delay` (не меньше 2 сек, по умолчанию 4), `--no-cache`.

## Вежливость к сайту

- Собственный разбор robots.txt (с `*` и `$`); если robots не прочитан — доступ запрещён.
- Только разрешённые хосты, в т.ч. при редиректах.
- Честный User-Agent `VinPartsHelper/0.1.0`. Укажите контакт: `set VINPARTS_CONTACT=you@example.com`.
- Пауза между запросами, кэш на диске (7 дней, ETag/Last-Modified), лимит размера 80 МБ.
- При 429/503 повторов нет.
- Перед скачиванием документа программа спрашивает подтверждение (`--yes` — не спрашивать).

## Про LLM

Для vwts.ru он **выключен**: владелец сайта закрыл доступ AI-краулерам. Анализ идёт
локально правилами (шаблоны «Always replace», «must be replaced», «Do not reuse»,
заголовки пунктов и т.п.) с глоссарием EN→RU. Данные хранятся: `VINPARTS_HOME` или
каталог platformdirs.

## Как добавить другой источник (Toyota, ALLDATA API, папка с PDF)

1. Создайте `vinparts/sources/<name>.py` с классом-наследником `SourceAdapter`
   (`supports`, `refresh_index`, `find_documents`, `list_resources`, `read_resource`)
   и заполните `SourceTerms` (разрешено ли автоматическое чтение / LLM).
2. Добавьте адаптер в `sources/__init__.py` (`all_adapters`, `allowed_hosts`).
3. Ядро (`pipeline`, `extract`) менять не нужно — пример в `tests/test_pipeline.py` (FakeToyota).

## Ограничения

- Тесты идут на синтетических образцах; внутренние страницы vwts.ru не видел —
  разбор построен по главной странице. Отсюда `recon`: пришлите его вывод и
  сохранённый HTML, я подстрою парсер.
- Извлечение правилами не идеально: возможны пропуски и лишние пункты.
- Номера деталей не извлекаются (по постановке не требуются).
- Robots.txt — не разрешение на использование контента; для постоянного кэша
  рекомендуется написать владельцу сайта.
