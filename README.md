# VinPartsHelper — помощник механика (этап 1: сайт vwts.ru)

Консольная программа: по модели/двигателю и названию операции («цепь ГРМ») находит
руководство на vwts.ru и показывает, какие ещё детали нужно заменить вместе с ней —
с пометкой **обязательно / рекомендуется / по условию / проверить**, цитатой и ссылкой
на источник.

> Результат строится автоматически из текста руководства и **требует проверки по
> первоисточнику**. Это справочник, а не замена официальной документации.

## Запуск окна приложения (рекомендуется)

Требования к окну: на Windows нужен **Microsoft Edge WebView2 Runtime**. Он есть в Windows 11 и в
большинстве обновлённых Windows 10; если его нет, программа напишет об этом и откроется в браузере
(тогда скачайте «Evergreen Runtime» со страницы developer.microsoft.com/microsoft-edge/webview2).
Ссылки на источники открываются в обычном браузере, остальное остаётся внутри окна.
Запуск с `--browser` показывает интерфейс во вкладке браузера.



## Про скраперы и скорость

Скорость поиска ограничена не инструментом, а вежливой паузой между запросами к сайту, и её не нужно
обходить: сайт закрыл в robots.txt многих роботов (Wget, SEO-пауков, ИИ-краулеров). Быстрее и честнее так:
один раз загрузить все модели (индекс хранится локально), держать скачанные руководства в библиотеке
и читать их с диска. Тогда поиск идёт мгновенно, и сайт не нагружается.

## Установка вручную (Windows, PowerShell)

```powershell
cd vinparts_project
py -3.14 -m venv .venv      # или py -3.13
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m vinparts --help
```

macOS / Linux:

```bash
python3.14 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m vinparts --help
```

Тесты (работают офлайн): `pip install -r requirements-dev.txt && pytest`

## Команды

| Команда | Что делает |
|---|---|
| `python -m vinparts gui` | Оконное приложение (см. выше) |
| `python -m vinparts vin WVWZZZ...` | Расшифровка VIN (марка, год; WMI только VAG) |
| `python -m vinparts ops` | Список поддерживаемых операций |
| `python -m vinparts recon` | **Запустите первой.** Скачивает главную vwts.ru и показывает, что распознано |
| `python -m vinparts recon --url https://vwts.ru/vw_golf7_5g.html` | То же для страницы модели |
| `python -m vinparts index [--model golf]` | Строит локальный индекс документов (SQLite) |
| `python -m vinparts docs` | Что лежит в индексе |
| `python -m vinparts ask --op "цепь грм" --model golf --engine CJSA --year 2013` | Основной запрос |
| `python -m vinparts analyze-file файл.pdf --op "цепь грм"` | Анализ локального PDF/HTML/TXT (без сети) |

Глобальные опции: `--data-dir`, `--delay` (не меньше 2 сек, по умолчанию 4), `--no-cache`.

## Как добавить другой источник (Toyota, ALLDATA API, папка с PDF)

1. Создайте `vinparts/sources/<name>.py` с классом-наследником `SourceAdapter`
   (`supports`, `refresh_index`, `find_documents`, `list_resources`, `read_resource`)
   и заполните `SourceTerms` (разрешено ли автоматическое чтение / LLM).
2. Добавьте адаптер в `sources/__init__.py` (`all_adapters`, `allowed_hosts`).
3. Ядро (`pipeline`, `extract`) менять не нужно — пример в `tests/test_pipeline.py` (FakeToyota).

## Ограничения

- Тесты идут на синтетических образцах; внутренние страницы vwts.ru не видел —
  разбор построен по главной странице. Отсюда `recon`: пришлите его вывод и
  сохранённый HTML, я подстрою парсер.
- Извлечение правилами не идеально: возможны пропуски и лишние пункты.
- Номера деталей не извлекаются (по постановке не требуются).
- Robots.txt — не разрешение на использование контента; для постоянного кэша
  рекомендуется написать владельцу сайта.
